# 2. Обґрунтування вибору та опис корпусу даних

## 2.1. Призначення корпусу

Для розроблення RAG-системи AI Concept Explorer необхідний корпус текстових документів, що містять пояснення концепцій штучного інтелекту, їхніх взаємозв'язків, практичного застосування та теоретичних передумов.

Корпус використовуватиметься для пошуку релевантної інформації за допомогою векторного пошуку та BM25, а також для формування мовною моделлю відповідей із посиланнями на джерела.

## 2.2. Обрані джерела даних

Для формування корпусу обрано два відкриті джерела з екосистеми Hugging Face.

**1. Hugging Face Transformers Documentation**

- **Джерело:** https://github.com/huggingface/transformers
- **Каталог:** `docs/source/en/`
- **Формат:** Markdown (`.md`)
- **Мова:** англійська
- **Ліцензія репозиторію:** Apache License 2.0
- **Кількість файлів:** 769

Документація містить технічні та концептуальні матеріали про архітектури нейронних мереж, мовні моделі, механізми уваги, токенізацію, навчання та використання AI-моделей.

**2. Hugging Face LLM Course**

- **Джерело:** https://github.com/huggingface/course
- **Каталог:** `chapters/en/`
- **Формат:** MDX (`.mdx`)
- **Мова:** англійська
- **Ліцензія навчальних матеріалів:** Apache License 2.0
- **Кількість файлів:** 104

Курс містить структуровані навчальні матеріали про Transformers, токенізацію, мовні моделі та їхнє практичне застосування. Матеріали орієнтовані на послідовне вивчення AI-концепцій і містять приклади їх використання.

## 2.3. Попередній обсяг корпусу

Кількість файлів визначено за допомогою GitHub REST API шляхом отримання рекурсивного списку файлів відповідних репозиторіїв.

| Джерело даних | Кількість файлів | Формат |
|---|---:|---|
| Transformers Documentation | 769 | Markdown |
| Hugging Face LLM Course | 104 | MDX |
| **Разом** | **873** | |

Початковий набір містить 873 файли, що відповідає встановленому методичними вказівками діапазону від 500 до 10 000 документів за кількістю.

Остаточний обсяг корпусу буде визначено після перевірки вмісту, видалення нерелевантних і службових матеріалів та можливих дублікатів.

## 2.4. Обґрунтування вибору

Обрані джерела доповнюють одне одного: Transformers Documentation надає детальну технічну інформацію про сучасні AI-моделі та їх використання, тоді як LLM Course містить навчальні пояснення основних концепцій.

Основні переваги обраного корпусу:

- Відкритий доступ до матеріалів.
- Покриття сучасних концепцій AI, зокрема Transformers, LLM, embeddings та механізмів уваги.
- Наявність теоретичних пояснень і практичних прикладів.
- Використання форматів Markdown та MDX, придатних для програмної обробки.
- Можливість збереження ідентифікаторів документів, заголовків та URL для подальшого цитування.

## 2.5. Попередня перевірка та обмеження

Під час попередньої вибіркової перевірки дев'яти документів із різних категорій встановлено, що навчальні матеріали LLM Course містять зрозумілі пояснення AI-концепцій, тоді як частина Transformers Documentation орієнтована переважно на використання бібліотеки та опис програмних інтерфейсів.

Виявлено такі потенційні обмеження:

1. **Службовий вміст.** Окремі файли містять переважно технічні описи API або конфігурації, які можуть бути малокорисними для навчальних пояснень.
2. **Спеціалізована розмітка.** Файли MDX можуть містити додаткові компоненти, що потребуватимуть очищення зі збереженням змістовного тексту.
3. **Тематичне покриття.** Матеріали переважно присвячені практичному AI Engineering, тому математичні основи окремих концепцій можуть бути висвітлені недостатньо.
4. **Обсяг після фільтрації.** Кількість придатних документів може зменшитися після очищення та видалення дублікатів. Якщо вона стане меншою за 500, необхідно буде переглянути критерії відбору або додати інші відкриті джерела.
5. **Ліцензійні умови.** Обрані репозиторії використовують Apache License 2.0, однак перед повторним розповсюдженням потрібно перевірити наявність сторонніх матеріалів з іншими умовами використання.

Повне завантаження, очищення, нормалізація та розбиття документів на фрагменти виконуватимуться в межах лабораторної роботи №2.

## 2.6. Висновок

Для AI Concept Explorer обрано комбінований корпус на основі Hugging Face Transformers Documentation та Hugging Face LLM Course.

Початковий набір містить 873 англомовні файли, які охоплюють основні поняття та практичні аспекти сучасного штучного інтелекту.

Поєднання технічної документації з навчальними матеріалами дозволить використовувати корпус для пошуку інформації та генерації обґрунтованих пояснень у RAG-системі.

Остаточний склад і придатність корпусу буде перевірено під час підготовки даних у лабораторній роботі №2.
