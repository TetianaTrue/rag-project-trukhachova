# AI Concept Explorer
AI Concept Explorer — навчальний RAG-асистент для вивчення штучного інтелекту (AI) та великих мовних моделей (LLM).
Система призначена для студентів, розробників та всіх, хто хоче краще розуміти AI-технології, їхні принципи роботи та взаємозв'язки.

## Основні можливості (заплановані)
- Пояснення понять AI та LLM.
- Пошук інформації в навчальних документах.
- Пояснення зв'язків між поняттями та необхідних попередніх знань.
- Формування відповідей із посиланнями на джерела.
- Підтримка запитань українською та англійською мовами.

Взаємодія із системою здійснюватиметься через командний рядок (CLI).

## Корпус даних
Для системи обрано два джерела:

1. [Hugging Face Transformers Documentation](https://github.com/huggingface/transformers) — технічна документація моделей.
2. [Hugging Face LLM Course](https://github.com/huggingface/course) — навчальні матеріали про мовні моделі.

Попередній обсяг корпусу — 886 текстових файлів, визначених за допомогою GitHub REST API.

## Встановлення середовища
Для майбутньої реалізації системи необхідно:

1. Встановити Python та Git.
2. Клонувати репозиторій:

   `git clone https://github.com/TetianaTrue/rag-project-trukhachova.git`

3. Створити віртуальне середовище Python:

   `python -m venv .venv`

4. Активувати середовище у Windows PowerShell:

   `.\.venv\Scripts\Activate.ps1`

5. Встановити основні бібліотеки:

   `pip install chromadb sentence-transformers ollama`

6. Встановити [Ollama](https://ollama.com/) та завантажити модель:

   `ollama pull qwen2.5:3b`

Наведені команди призначені для підготовки середовища.
